# AppBar

56px top bar. Root screens: wordmark + account switcher chip + alerts. Inner screens: back + title + one overflow action.

- Classes: `tt-appbar` > content; `tt-appbar__title` (18/26 semibold, ellipsis); `tt-wordmark` sets "Track**Trade**" in Inter 700 with "Trade" in `brand-600` (there is no logo file — the wordmark is type).
- Account switcher chip filters every screen ("ทุกบัญชี" or one account, F-02 AC3).
- Sticky, `surface` with `border` bottom; `z-nav`.
