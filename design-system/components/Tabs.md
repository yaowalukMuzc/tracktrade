# Tabs

Underline tabs for sibling sections of one page (Performance: ภาพรวม · Behavior · Breakdown · Diagnosis; Trade detail: Chart · Review · Timeline).

- Classes: `tt-tabs` > `tt-tab` (`--on` = `brand-600` text + 2px underline). Scrolls horizontally on mobile; never wraps.
- Use SegmentedControl instead when the options filter the same content.
