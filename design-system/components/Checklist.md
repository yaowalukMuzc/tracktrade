# Checklist

Setup checklist answered inside a Trade Plan (F-06 AC3). Required items block Plan Lock until checked.

- Structure: list of `tt-check` (`--done` checked, `--missing` required and unchecked after a lock attempt) > `tt-check__box` + `tt-check__text` with an optional "จำเป็น" badge.
- Consumer provides: items from `setup_checklist_items` (order, text, is_required), answers, optional note per item.
- Show the count on the Lock button: "ล็อกแผน (2/3)".
